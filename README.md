# eBook Bite For SSAFY

![이미지](/public/icon128.png)

eBook을 물어오는 강아지<sup>(※귀엽다)</sup>

안그래도 부족한 화면을 잡아면는 eBook 팝업

이 익스텐션은 eBook을 팝업 대신 브라우저 탭으로 열어줍니다.

## 사용방법

> [!IMPORTANT]
> 해당 확장 프로그램은 학습 편의성의 목적으로만 사용해주세요

### 1. 프로젝트 클론 받기

```
git clone https://github.com/neruu00/eBookBiteForSSAFY.git
```

### 2. 확장 프로그램 들어가기

크롬의 확장 프로그램 페이지로 들어간다

주소창에 ```chrome://extensions/``` 링크 복사 후 붙여넣기

### 3. 확장 프로그램 로드

1. 좌측 상단 `압축해제된 확장 프로그램 로드` 클릭
   - `압축 해제된 확장프로그램 로드` 버튼이 없다면 우측 상단에 `개발자 모드` 스위치를 클릭

2. 클론 받은 프로젝트 폴더 선택
